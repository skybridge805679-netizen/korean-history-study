# 문제 그림 변경 기록

## 2026-10-12 추가 변경 및 미소녀풍 보정

| 문제 | 변경 영역 |
| --- | --- |
| 70-19, 71-6, 71-26, 71-31, 72-18, 72-32, 73-17, 73-35, 74-10, 75-41, 76-26, 78-4, 79-31, 79-34 | 이름 없는 대화 인물 |
| 71-17, 73-44, 74-32 | 질문하는 익명 인터뷰어만 변경; 역사 인물인 답변자는 보존 |
| 71-18 | 포스터 왼쪽 위의 익명 관광객; 지도와 지명은 보존 |
| 74-22 | 오른쪽 대화 인물; 왼쪽 국왕·신하 장면과 가운데 시간 구간 표시는 보존 |

19개 그림의 익명 인물은 기존 그림과 어울리는 미소녀 애니메이션풍의 성인 여성 캐릭터로 표현한다. 큰 눈, 섬세한 얼굴, 부드러운 머리카락과 셀 채색을 사용하며, 한복·인터뷰 복장과 원래의 자세·배치는 유지한다. 실제 역사 인물은 미소녀 캐릭터로 바꾸지 않는다.

두 명 이상 등장하는 그림은 얼굴형·눈매·눈썹·헤어스타일·머리색·표정을 인물별로 다르게 지정한다. 같은 얼굴에 머리색만 바꾸는 방식은 사용하지 않는다. 두 패널에 총 네 명이 나오는 대화와 포스터의 다섯 명도 각각 구별되는 외모로 표현한다.

추가한 19개 SVG는 `../fig/문제번호.jpg` 원본을 첫 이미지 레이어에 그대로 포함한다. 이미지 생성 도구로 수정한 그림은 `clipPath`로 제한한 인물 영역에만 표시한다. 새로 생성된 그림의 글자나 자료 영역을 사용하지 않는다. 원본 JPG, 문제 문장, 보기, 해설, 정답, `IMG`·`FIG` 자료는 변경하지 않았다. `index.html`의 `CHARACTER_KEYS.push(...)`가 새 그림을 연결한다. 이미지 요청의 버전 문자열을 갱신해 기존 여성 삽화가 브라우저 캐시에 남지 않게 한다.

실제 역사 인물의 사진·초상·발언 장면, 문화유산과 유물 속 인물 표현, 정답 판단에 필요한 자료는 성별 변경 대상에서 제외한다. 기존 159개 SVG의 첫 레이어도 각 원본 파일 또는 내장 원본 이미지와 바이트 단위로 일치한다.

## 검증

- 500문항의 문장·보기·정답·자료 연결 정보가 변경 전과 동일함을 확인했다.
- 그림이 있는 326문항 모두 이미지가 표시되고 디코딩되는지 브라우저에서 확인했다.
- 추가 변경한 19문항 각각의 그림 표시와 정답 채점을 확인했다. JavaScript 실행 오류는 없었다.
- 새 그림 19개의 보호한 글자 영역, 인터뷰의 역사 인물, 74-22의 국왕 장면을 원본과 픽셀 단위로 비교했다.

## 원본 시험지 대조 및 복구 완료 (2026-10-12)

사용자가 제공한 제70–79회 심화 시험지 10개 PDF와 500문항을 대조했다. 기존에 자료 이미지가 연결되지 않고 글로만 표시되던 174문항은 원본 시험지의 자료 그림으로 복구했다. 기존 자료를 포함한 500문항 모두 크롭을 다시 추출해 자료 테두리, 말풍선, 표, 시간 구간, 그림 선택지와 `<보기>`가 빠지지 않게 했다. 제72회 47·48번의 공통 지문은 두 문항 모두 표시한다.

기존 미소녀 그림 178개는 원본 PDF 자료 위로 위치·크기를 다시 맞췄다. 복구 중 발견한 제76회 6번과 제77회 5번의 채팅 아바타도 각각 구별되는 네 명의 성인 여성 캐릭터로 변경해 총 180문항에 적용했다. 익명 인물만 변경하며 실제 역사 인물과 자료 속 초상·유물·사진은 보존한다. 기존 `character-art`는 원본 작업 기록으로 유지하고, 실제 화면은 새 `question-art`와 `question-materials`를 사용한다.

원본의 인쇄된 글자가 인물 그림 위에 겹치는 영역 526개는 PDF의 실제 픽셀을 다시 얹어 보호했다. OCR은 보호 영역을 찾는 데만 사용했으며 문제 속 글자를 OCR 결과로 다시 작성하지 않았다. 그림의 최대 높이 제한을 제거해 긴 자료도 원래 비율로 표시하고, 확대 화면에서 1000px 이상으로 보고 좌우·상하로 이동할 수 있게 했다. 기존 글 자료는 ‘자료를 글로 읽기’에서 계속 제공한다.

500개 자료의 크롭 범위와 원본 PDF 해시, 그림 위치 보정 및 보호 영역은 [source-map.json](../question-materials/source-map.json)에 기록했다. 재추출 방법은 [원본 자료 기록](../question-materials/README.md)을 참고한다.

### 최종 화면 검증

- 500문항의 문제 문장·선택지·정답·기존 `IMG`·`FIG` 데이터는 변경 전과 동일하다.
- 500개 자료 모두 브라우저에서 로드·디코딩되며 기록한 크기와 일치한다.
- 1280px·390px·360px 화면에서 500문항 모두 그림 비율을 유지하고 가로로 넘치지 않는다.
- 복구 자료, 공통 지문, 그림 선택지, 새 아바타 및 추가 변경한 인물을 포함한 28문항의 정답 채점과 저장을 확인했다.
- 모바일 자료 확대·스크롤과 새로고침 뒤 학습 기록 유지가 정상이며 JavaScript 오류가 없다.
- 원본 500개 크롭 및 보정한 인물 그림 180개를 전체 모아보기로 검토했다.
- 무손실 압축한 원본 자료 500개는 RGBA 픽셀 해시가 일치한다. 인물 그림 180개의 최종 브라우저 렌더링도 압축 전과 픽셀 단위로 같고, 보호한 인쇄 글자 526개 영역은 원본 PDF 자료 픽셀과 일치한다.
- 재추출 도구로 공통 지문(72-48), 새 아바타(76-6), 위치 보정 인물(79-3), 그림 선택지(78-26)의 원본 자료를 다시 만들어 픽셀 해시가 일치함을 확인했다.

## 사진 선택지·의상 후속 개선

49문항의 의상을 다양하게 개선하고, 70-37·79-45·77-10·77-25의 익명 인물 미소녀화, 78-34의 머리 잔상 제거, 78-14의 장면 개선을 추가했다. 현재 인물 그림은 총 184문항에 적용한다. 문화재 사진 선택지 21문항은 사진을 각각 답안 버튼으로 분리했다. [의상 변경 기록](../appearance-art/README.md)과 [사진 선택지 기록](../choice-art/README.md)을 참고한다.
