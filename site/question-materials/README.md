# 원본 문제 자료 복구 기록

2026-10-12 사용자가 첨부한 제70–79회 한국사능력검정시험 심화 문제지 PDF 10개를 기준으로 500문항의 자료 그림을 다시 추출했다. 문제 제목과 일반 텍스트 선택지는 앱의 기존 데이터를 사용하며, 자료 안의 표·말풍선·그림·지도·사진·`<보기>`와 그림 선택지는 원본 PDF 렌더링을 사용한다. 제72회 47·48번의 공통 지문은 두 문항에 모두 제공하고, 48번에는 해당 `<보기>`를 함께 배치했다.

`question-figures.js`가 문항별 파일과 크기를 연결한다. 원본 자료는 1000px 폭 기준의 무손실 WebP이며, 인물 변경 대상 180문항은 `../question-art/`의 SVG를 사용한다. SVG에는 PDF 원본 자료, 기존 인물 레이어의 위치 보정, 원본 인쇄 글자 보호 영역을 함께 저장한다. 기존 JPG와 인물 작업 SVG는 보존한다.

## 출처와 재현

[source-map.json](source-map.json)은 문항별 원본 PDF 파일명·SHA256, 페이지 번호(1부터), 크롭 사각형(PDF point), 렌더 배율, 픽셀 시작 좌표·크기·RGBA 픽셀 SHA256 및 최종 파일 SHA256을 기록한다. 여러 자료 구간은 25px 간격으로 배치한다. `restoredFromText`는 이전에 자료 이미지 연결이 없었던 문항이며, `artSource`·`artMatrix`·`protectedTextRects`는 인물 변경과 원본 글자 보호 근거다. 원본 PDF는 사용자 첨부 자료이므로 저장소에 중복 포함하지 않는다.

재추출 도구는 앱 실행과 별개로 PyMuPDF와 Pillow가 필요하다. 최초 추출은 PyMuPDF 1.26.6 / Pillow 12.3.0을 사용했다. 픽셀 해시가 다르면 도구가 중단하므로 다른 렌더러 버전으로 원본을 조용히 덮어쓰지 않는다.

```sh
python3 tools/rebuild_question_materials.py --pdf-dir /path/to/original-pdfs --output-dir /tmp/rebuilt-materials
# 일부 문항만 확인
python3 tools/rebuild_question_materials.py --pdf-dir /path/to/original-pdfs --output-dir /tmp/rebuilt-materials --keys 72-48 76-6
```

재추출 파일의 무손실 압축 설정에 따라 파일 바이트 해시는 달라질 수 있으나 RGBA 픽셀은 동일해야 한다. 새 인물 그림을 생성하지 않고 기존 인물 레이어를 재사용한다.
