# 사진 선택지 분리 기록

원본 시험지의 문화재·작품 사진을 고르는 21문항에서 사진 105개를 답안 버튼 안으로 옮겼다. 자료 그림에는 질문에 필요한 장면만 남기고, 사진을 클릭하면 기존 답안 번호를 선택한다. 별도의 ‘사진 확대’ 버튼은 채점이나 답안 선택 없이 사진만 확대한다.

풀이 전에는 사진과 보기 번호만 제공한다. 보기의 명칭을 미리 표시하면 시대나 작가를 판단하는 단서가 되므로, 연습 문제에 답한 뒤 사진 밑 이름과 해설의 ‘보기별 문화재·작품’ 표를 표시한다. 모의고사 진행 중에는 이름과 해설을 표시하지 않는다.

사진은 원본 PDF의 이미지 객체에서 직접 추출했으며 AI로 문화재를 다시 그리지 않았다. 원래 이미지의 투명 마스크를 흰 배경과 합성하고 무손실 WebP로 저장했다. 원본 이미지 객체 번호(`sourceXref`), PDF 내 좌표, 파일·픽셀 SHA256은 `../question-materials/source-map.json`의 `choiceImages`에 기록했다.

95개 사진에는 확인 가능한 문화재·작품의 이름을 보완했다. 10개는 원본 자료만으로 세부 명칭을 확정하기 어려워 `nameStatus: description`으로 기록하고, 해설에서 ‘사진 특징’으로 구분해 설명한다. 확정되지 않은 작가·유물 명칭을 추측해 정식 명칭으로 표시하지 않는다. 해당 보기: 72-23-3, 73-6-1, 73-6-2, 73-26-2, 76-17-2, 76-17-3, 76-17-5, 78-9-2, 78-9-5, 78-26-3.

제71회 7번 ④의 기존 ‘칠곡 송림사 오층 전탑으로 추정’ 해설은 사진에 맞는 ‘안동 법흥사지 칠층 전탑’으로 바로잡았다. 모든 정답 번호와 선택지 순서는 유지했다.
