# 제80회 익명 인물·의상 다양성 재작업

이 기록이 `20261018-round80`의 49문항 일괄 재제작 결과를 대체한다.

- 원본에 익명 인물이 있는 21문항만 변경했다: 7, 9, 10, 14, 17, 18, 24, 25, 26, 27, 28, 29, 30, 31, 34, 39, 41, 43, 44, 46, 48.
- 나머지 29문항은 최초 원본 자료 연결로 복원했다. 인물 없는 사료·문서·사진에 진행자를 추가하지 않으며, 4번의 신라 왕 등 실제 역사 인물도 원본으로 되돌렸다.
- `designs.json`에 인물별 얼굴·눈매·머리·표정·의상을 각각 지정했다. 탐방복, 메이드, 마법사, 한복, 사서, 아이돌, 캐주얼, 앵커 복장 등을 구분하고 여러 사람이 있는 문항의 외모도 다르게 지정했다.
- 실제 역사 인물과 역사 자료의 정체성·내용, 원문의 문장과 빈칸을 유지하도록 생성했다. 43번 김규식, 46번 화면 속 역사 인물, 48번 대통령 내외는 변경 대상에서 제외했다. 48번에서 역사 인물이 잘못 바뀐 첫 결과는 사용하지 않았다.

최종 연결 파일 21개는 각 기록의 `generated` PNG를 바이트 그대로 복사한 것이다. 이미지 위에 시험지·글자·사진 조각을 추가하지 않았고, 자르기·재압축도 하지 않았다. 작업 중 만든 합성 SVG, 마스크 및 합성 코드는 제거했으며 최종 연결에는 포함하지 않는다. 80회 밑줄 보정 오버레이도 사용하지 않는다. 생성 과정에서 원문을 다시 그리므로 원본 자료와의 픽셀 일치를 주장하지 않는다.

`manifest.json`과 문항별 JSON에 프롬프트, 생성 원본 경로, 표시 파일, 크기, SHA-256을 기록했다. 원본 29문항 연결·기존 70~79회 500문항 연결·문제 및 선택지 정보의 보존과 생성 PNG 바이트 일치를 검사한다. 1280·390·360px에서 80회 50문항의 이미지 디코딩·가로 넘침·추가 오버레이 부재 및 확대 기능을 확인한다.
