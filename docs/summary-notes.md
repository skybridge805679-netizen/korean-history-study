# 요약노트(손필기식 한 장 정리) 작성 규칙

`site/summary/*.js` 에 시대별 한 장짜리 정리를 둔다. 화면은 공부 자료 → 요약노트 탭이다. 검사: `node tools/check_summary.js [-v]`.

## 데이터 형식
```js
(window.SUMMARY_SHEETS=window.SUMMARY_SHEETS||[]).push({
 id:"ancient-1", era:"선사", eras:["선사","초기국가","삼국"],   // eras: 이 장이 다루는 QS.era 값들(커버리지 검사 기준)
 title:"선사 시대 ~ 삼국 시대",
 sections:[ {h:"[고구려]", w:"full"|생략(반 칸), body:[ 블록… ]} ]
});
```
블록: `{grid:{cols:[…],rows:[[행머리,셀,셀…]]}}`(셀 문자열은 `\n`으로 줄바꿈, 셀을 `{t:"…",hl:true}`로 쓰면 금색 테두리 강조) · `{line:"…",ind:0}` · `{note:"작은 회색 메모"}` · `{tree:{t:"뿌리",c:[{t:"가지",c:[…]},"잎"]}}` · `{flow:["a","b","c"]}`(→로 연결) · `{gallery:[{img:"choice-art/79-6-1.webp",name:"부여 정림사지 오층 석탑",note:"백제 · 평제탑",q:"79-6"}]}`.

## 인라인 표시 `{x:문구}` (중첩 불가)
- `{r:…}` 빨강 — 기출의 정답 단서·빈출 핵심. 한 칸의 절반 이하로만 쓴다.
- `{b:…}` 파랑 — 제도·법·문화·서적·유물 이름.
- `{g:…}` 초록 — 인물·전쟁·외교·조약.
- `{y:…}` 형광펜 · `{x:…}` 금색 네모(정말 자주 나오는 것) · `{n:…}` 작은 회색 메모 · `{s:…}` 빨간 취소선(~X, 오답 함정).
- 〈책 이름〉 은 그냥 〈 〉 문자로 쓴다. 화살표는 → 문자.
- r/b/g/y/x 용어는 화면에서 70~80회 기출 문항 수가 자동으로 붙고, 누르면 그 문항들을 푼다. 따라서 용어는 기출 본문에서 쓰이는 표기로 쓴다.

## 작성 원칙
- 70~80회 550문항(`QS`, `q.exp`, `site/question-explanations.js`, `site/core-notes/*.js`)에 나온 단서·정답·오답 선지 주인공을 우선한다. 문제에서 묻지 않는 곁가지는 줄인다.
- 암기 단위의 키워드 중심. 문장으로 풀어 쓰지 말고 `주체: 핵심어·핵심어` 형태로 압축한다.
- 같은 칸에서 헷갈리는 쌍(예: 근초고왕/침류왕/아신왕)은 서로 대비되게 나란히 둔다.
- 사실은 확실한 것만 쓴다. 불확실하면 쓰지 않는다.
- 사진·문화재는 반드시 이미지 파일을 직접 열어(Read) 이름과 맞는지 확인하고, 사용한 파일만 gallery에 넣는다.
