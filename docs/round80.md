# 제80회 심화(2026.10.17) 추가 기록

사용자가 첨부한 제80회 심화 문제지 PDF(12쪽)와 정답표 PDF로 50문항을 추가했다. 사이트는 이제 70~80회 550문항이다.

## 넣은 것

- 문항·보기·정답·배점: 문제지 글자 층에서 추출했고, 정답 빈도(① 11·② 10·③ 9·④ 9·⑤ 11)와 배점 합계(1점 10·2점 30·3점 10)를 정답표와 대조했다.
- 자료 그림: 문제지 PDF의 자료 영역을 폭 약 1000px 무손실 WebP로 잘라 `site/question-materials/80-N.webp`에 두었다. 사진 보기 문항(3·13번)은 `question-prompts/80-N.webp`와 `choice-art/80-N-k.webp`로 나눴다. 기존 회차에 적용한 캐릭터·장면 그림 변경은 하지 않았고 원본 그대로다.
- 문항별 해설: `site/question-explanations.js`에 80회 50문항(단서·정답 근거·보기 5개·기억할 점)을 70~79회와 같은 형식으로 넣었다. 문항 데이터(`QS`)의 시대·주제·짧은 해설도 함께 작성했다.
- 핵심노트 연결: 미연결이던 80-24(창덕궁)·80-28(신미양요)·80-43(김규식)·80-50(진주)을 기존 노트의 `match`에 잇고, 진주 노트(`regional-jinju`)를 새로 만들었다. 시간 조건 문항 15·33·37·38번은 `question-note-timelines.js`에 시간축을 넣었다.
- 화면 문구·검사 도구의 회차 범위와 문항 수를 70~80회 550문항으로 바꿨다.

## 확인이 약한 부분(보강 대상)

- 3번 ③번 사진은 이름을 확정하지 않고 "높고 가는 다층 석탑"으로 서술했다. 13번 ②·③번 사진도 이름 없이 형태만 서술했다.
- 해설 작성 중 근거를 기존 500문항에서 확인하지 못해 교과서 수준 지식으로 쓴 곳: 6번 ①(대통력), 8번 ①·③(해동성국, 수덕만세·정개 연호), 12번 ⑤(반전도감)·광군 조직 시기, 21번 ④(구황촬요), 34번 ①(활빈당 대한사민논설), 37번 참의부 편성 연도, 49번 ③(다문화 가족 지원법).
- 27번(숭정금실 편액)은 질문이 조선의 대명 정책이라 기존 73-22처럼 조선전기로 분류했다. 자료는 조선 후기다.
- 19번은 79-20(과전법)과 같게 조선전기/토지 제도로 분류했다. 자료의 연대는 1391년 고려 말이다.

## 최초 추가 시 남은 작업

- 요약노트·주제별 핵심노트 본문과 근거 문구는 아래 2026.10.18 보강에서 갱신했다.
- 80회 문항에는 사진·장면 그림 재작업, 밑줄 표시 좌표(`question-underlines.js`)가 없다. 밑줄은 원본 이미지 안의 것을 그대로 쓴다.
- 문화재 사진 이름이 확정되지 않은 항목은 기존의 형태 설명을 유지한다.


## 2026.10.18 학습 자료 보강

기존 80회 문항·정답·사진 크롭을 유지하면서 주제별 핵심노트 40개에 비교표 44행, 요약노트 14장에 자료 단서·혼동 구별 44항목을 보강했다. 기존 노트의 해당 주제 아래에 합쳐 표시되므로 문제 해설에서 연결하는 노트와 공부 자료의 노트가 함께 갱신된다.

- 고대: 고추가·연노부·절노부, 김군관 교서, 발해의 대당 서열 다툼·해동성국, 체징·보림사, 견훤의 무진주·후당 교류.
- 고려: 광군 조직 시기와 현종 때 침입 구분, 마도·죽찰, 요세의 참회·염불, 은입사 기법, 최무선과 조선의 화약 무기·전투 인물 비교.
- 조선: 과전법 18과·현직과 산직, 상대별곡과 사헌부, 기유약조, 숙종의 환국 구분, 소청 운동, 숭정금실·조천사, 창덕궁 전각.
- 근대·일제: 육영공원 좌·우원, 석조전 공사와 경인선 개통 선후, 독립 협회의 절영도·한러 은행 반대, 참의부의 위치, 개량 한옥, 하와이와 윌로우스 구별.
- 현대·통합: 김규식의 활동 연결, 전쟁 중·전 구분, 초등학교 개칭·총독부 철거, 정부별 사회 정책·통일 정책, 진주 지역사.
- 요약노트 상단의 회차·문항 수는 현재 ROUNDS와 QS로 계산하도록 변경했다. 근거 범위는 70~80회 550문항이다.
- 80-8의 오답 해설 중 잘못 나열한 양계 이름을 북계·동계로 바로잡았다.

검증: 첨부 답지와 80회 정답·배점 50개 대조, 해설 550개 검사, 문항별 복습 노트 550개/보기 2,750개 검사, 주제 노트 미연결 0개, 요약노트 형식·이미지·참조 검사. 단서 누락 검사는 문장 조각도 누락으로 집계하므로 완전성 판정으로 쓰지 않는다. 사진 이름 미확정 항목과 외부 사료 확인이 약한 항목은 위의 확인 대상으로 남긴다.


## 2026.10.18 자료 장면 재제작

80회 자료 장면 49개를 사용자 선택 그림인 76-24를 스타일 참고로 삼아 젊은 성인 미소녀 중심의 16:9 장면으로 재제작했다. 80-6은 생성 서비스 자동검사 거절로 원본을 유지했다. 나이 들어 보이는 얼굴과 정장 위주의 처음 9개 생성본은 적용하지 않았다. 캐릭터의 가상 대화 역할과 의상도 확인하고 실제 역사 사진·문화재 자료의 정체성은 보존한다.

완성 PNG는 생성 원본을 자르기·재압축·시험지 조각 합성 없이 그대로 사용한다. 사진 선택지와 정답·보기·해설·노트는 유지한다. 최종 완료/미완료 문항과 원본 해시는 [생성 기록](../assets/generated-scenes/20261018-round80/README.md)에 기록한다. 원본 밑줄은 결과 이미지에서 확인하며, 누락 시 이미지 바이트를 바꾸지 않는 기존 밑줄 표시 기능으로 보완한다.
