# 문항별 해설 보완

## 범위와 현재 진행

70~80회 총 **550문항 전부**를 보완했다. 각 문항에 자료의 결정적 단서, 정답 근거, 원문 순서의 보기 5개 해설, 기억할 점을 작성했다. 총 2,750개 보기의 판단 이유를 설명한다. 보완 표시는 집필·구조 점검의 진행 상태이며 외부 전문가 감수 완료를 뜻하지 않는다.

기존에도 `QS[].exp`에 문항별 짧은 해설이 있었다. 이번 작업은 주제별 개념노트를 대체하는 작업이 아니라, 각 문제의 단서·정답 근거·모든 오답의 이유를 충분히 설명하는 작업이다.

## 작성 기준

- 회차-문항 번호로 해설을 연결한다. 같은 주제의 문제라도 자료와 질문 조건에 따라 따로 작성한다.
- 자료의 결정적 단서와 그 단서가 가리키는 대상을 밝힌다.
- 질문의 ‘이후·사이·옳지 않은 것’ 같은 조건을 정답 근거에 반영한다.
- 보기 5개를 원문 순서대로 모두 설명한다. 틀린 보기는 올바른 인물·시대·제도를 적고 왜 조건에 맞지 않는지 쓴다.
- 사진 문제는 사진의 실제 문화재와 특징을 대조한다. 이번 79회 6번은 `question-figures.js`의 보기별 식별 정보와 대조했다.
- 자료가 가설·견해를 소개하면 확정된 사실로 바꾸어 서술하지 않는다.
- ‘기억할 점’은 해당 문항에서 혼동하기 쉬운 차이를 정리한다.

## 검증과 관리

전체 문항의 진행 상태는 [CSV 목록](question-explanation-audit.csv)으로 관리한다. 70~80회 각각 50/50문항이며 미보완 문항은 없다. 길이나 사진 여부는 검토 참고 정보이며 내용 부실의 자동 판정 기준이 아니다.

이번에 함께 바로잡은 항목은 다음과 같다.

- 78회 1번: 세형 동검은 철기 시대의 청동 무기로 설명했다.
- 79회 14번: 묘청의 난 발발(1135)과 진압(1136)을 구별했다.
- 73회 6번 ③, 75회 3번 ③, 76회 4번 ④: 사진을 확인하여 ‘이불병좌상’으로 잘못 표시된 철제 갑옷의 이름과 해설을 수정했다.
- 76회 27번 ②: ‘무녀신무(신윤복)’라는 기존 단정 표기를 제거하고 사진에서 확인 가능한 무속 의례 장면으로 설명했다. 정답 ③ 「월하정인」과 혼동되지 않게 했으며, 확인되지 않은 작가명은 새로 추정하지 않았다.

문제의 정답·보기 순서는 변경하지 않았다. 사진 보기 정보와 식별 오류가 의심되는 항목의 로컬 원본 문제지·사진을 대조했다. 식별 정보가 불충분한 사진은 확인 가능한 형태를 설명하고 고유명사·작가명을 임의로 확정하지 않았다.

해설 데이터는 `site/question-explanations.js`에 작성한다. 정답 번호는 검증용으로 원문 정답과 대조한다. 앱은 보완 문항의 전체 해설을 검색·용어 찾기에 사용하며, 검색 결과와 오답 목록에는 정답 근거를 요약 표시한다. 미보완 문항은 기존 해설을 표시한다.

```sh
python tools/audit_question_explanations.py
```

이 명령은 70~80회 550문항의 전체 연결, 정답 일치, 단서·정답 근거·전체 보기·기억할 점의 누락을 검사하고 CSV 목록을 갱신한다. 문항 하나라도 빠지면 실패한다. 사료 해석이나 역사적 사실의 정확성은 이 구조 검증만으로 보증되지 않는다.

2026-10-15 검증 결과:

- 500/500문항 연결 및 정답 대조, 2,500개 보기 해설의 누락 검사 통과.
- Chromium에서 500문항의 해설 생성과 답안 공개 전 해설 숨김 검사 통과.
- 연습의 해설 먼저 읽기·다시 풀기·답안 기록, 보완 본문 검색, 사진 보기 이름 표시 확인.
- 모의고사 풀이 중 해설 숨김, 제출 후 오답 해설 표시, 오답노트에서 재학습 확인.
- 대표적인 텍스트·사진·조합형 문제의 PC(1440px)·모바일(390px) 화면 너비 검사 통과. 자바스크립트 오류 없음.
- 원본 500문항 데이터와 정답·보기 순서가 작업 전과 동일함을 확인. JavaScript 문법 및 `git diff --check` 통과.


2026-10-19 제80회 해설 보강:

- 50문항 모두 자료 식별 → 질문 조건 → 정답 근거 → 원문 순서의 보기 5개 → 기억할 점의 순서로 다시 작성했다. 오답은 가능한 한 실제 주인공·국가·제도·연대를 밝히고 문항의 조건에 맞지 않는 이유를 연결했다.
- 국가의 경제(7번), 국가에 대한 대응(12번), 같은 왕 재위 중의 사건(23번), 지역 탐구(50번)처럼 답의 범위를 잘못 좁히기 쉬운 조건을 따로 설명했다.
- 사진 보기의 이름 세 개를 확정하고 해설·보기 캡션을 함께 정리했다. 3번 ③은 개성 경천사지 십층 석탑, 13번 ②는 농경문 청동기, ③은 호우명 그릇이다. 기존 사진의 크롭·파일은 바꾸지 않았다. 경천사지 탑·호우명 그릇은 기존 71-16·73-6의 사진과도 직접 대조했다.
- 18번 ②는 박연(벨테브레이), 29번 ③은 조불 수호 통상 조약, 43번 ⑤는 안창호로 오답의 주체를 구체화했다.
- 대통력 도입(1370), 반전도감(1328), 구황촬요(1554), 활빈당 선언(1900), 참의부(1924), 다문화 가족 지원법(2008)은 아래 사료·기관 자료로 대조했다. 15번의 금 사대 수용은 인종 때 1126년으로 바로잡았다.
- 80회 시간축을 4개에서 14개로 확충했다. 15번의 시간축은 보기 ⑤를 이자겸의 난이 아닌 금의 사대 요구 수용으로 정확히 표기했고, 37·38번의 누락 비교 사건도 추가했다.
- 70~79회 500개 해설의 내용, 전체 문항·자료문·보기 순서·정답·배점이 작업 전과 같은지 확인했다. 전체 550개 해설 및 2,750개 보기 연결 검사, 550개 문항별 복습 카드와 90개 시간축 검사, 핵심노트 연결 검사, JavaScript 구문·HTML 생성 검사, `git diff --check`를 수행했다. 이번 검증은 브라우저에서의 시각 검사와 별개이다.
