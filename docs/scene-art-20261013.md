# 생성 원화 반영 기록 — 2026-10-13

인계 ZIP의 생성 원화 243장 중 사이트 문항과 연결된 후보를 모두 원본 시험지와 나란히 놓고 검수했다.

## 처리 방법
1. 각 문항의 후보 원화를 원본 자료 크기에 맞춰 축소한다.
2. 원본 시험지의 말풍선 글자 문단을 찾아, 원화 속 같은 위치의 글자와 맞춰(크기·위치 자동 정합) **원본 글자로 덮어쓴다.** AI가 그린 오탈자(예: 70-13 "궁주"→"공주", 72-18 "자결"→"자격")는 이 단계에서 모두 원본 글자로 바뀐다.
3. 결과를 한 장씩 원본과 비교해 가장 나은 후보를 고르고, 문제가 남은 문항은 반영하지 않는다.
4. 72-26 지도 이름표("꿀림 서원")는 원본 "귤림 서원" 이름표로 교체했다.
5. 79-36은 사용자가 고른 두 인물 버전(가로형)을 사용했다. 말풍선 글이 원문과 일치함을 확인했다.

결과는 `site/scene-art/<문항>.webp`이며 `question-figures.js`의 `sceneArt: true` 항목이 이를 가리킨다. 이전 그림 파일은 그대로 남아 있다.
