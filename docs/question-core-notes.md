# 문항별 핵심노트 개선

2026-10-15, 70~79회 500문항에 문항 전용 복습 노트를 연결했다.

## 구성

- 자료의 결정적 단서: 해당 문항의 해설에서 작성한 단서.
- 보기의 표현 → 바른 연결·구별점: 5개 보기의 대상·시대·연도를 대조한다. 사진 문제는 보기 사진 이름을 사용하고, 불확실한 식별은 ‘사진 특징’으로 표시한다.
- 시간축 76개: 순서·연표·사이·전후 조건 문제의 기준 사건과 비교 사건을 별도 집필했다. 같은 해의 전후 관계와 기원전 연대도 표시한다.
- 답을 가리고 떠올리기: 단서·시간축·비교 내용을 접고 개별 또는 전체로 다시 확인한다. 선택할 보기 표시도 함께 숨긴다.
- 내가 헷갈린 보기: 실제로 선택한 오답의 행을 표시해 복습할 위치를 알려 준다. ‘해당하지 않는 보기’를 고르는 문제는 그 조건을 표시한다.
- 관련 주제까지 넓혀 보기: 기존 97개 주제 노트는 별도 펼침 영역에서 읽는다.

공부 자료의 핵심노트에서는 문항별·주제별 보기를 전환하고 회차·시대·검색어로 찾을 수 있다. `79-3`처럼 완성된 문항 번호는 정확히 일치하는 문항을 찾는다. 회차 필터의 기본값은 79회이며 ‘전체 회차’를 선택하면 500문항을 모두 검색한다. 문항 카드의 ‘이 문제 다시 풀기’는 해당 문제만 연습으로 연다.

## 데이터와 유지보수

`site/question-core-notes.js`는 기존에 문항별로 작성한 `question-explanations.js`의 단서와 보기별 판단 근거를 복습용으로 구성한다. 비교 내용은 최대 두 문장으로 먼저 보이고, 나머지 판단 근거도 펼쳐 읽을 수 있다. 날짜의 소수점은 문장 구분자로 처리하지 않는다. 같은 해설을 두 곳에 따로 집필하지 않아 사실 수정이 함께 반영된다.

`site/question-note-timelines.js`는 문항 번호별 시간축 76개를 담는다. 시간축 항목은 `[연도·시기, 사건]` 순서로 작성하며 문제의 맥락에 맞춰 배열한다. ‘경복궁 중건 1865~1868 → 병인양요 1866’처럼 기간 안의 사건을 대조하는 항목은 단순한 연도 오름차순을 의미하지 않는다.

문제 데이터, 정답 번호, 기존 해설과 주제 노트의 사실 내용, 개인 학습 기록 저장 형식은 변경하지 않았다. 문항별 핵심노트는 풀이 중에 공개하지 않으며 연습의 답안 확인·해설 먼저 읽기 또는 모의고사 제출 후에 표시한다.

## 검증

```sh
node tools/check_question_core_notes.js
node tools/check_core_notes.js
python tools/audit_question_explanations.py
```

- 문항별 노트 500개, 보기 연결 2,500개, 사진 문제 21개, 시간축 76개의 연결·내용 누락 검사 통과.
- 기존 97개 주제 노트의 형식·500문항 연결 검사 통과.
- Chromium에서 전체 500문항의 노트와 시간축 생성, 답 공개 전 숨김을 확인했다.
- 답 가리기와 개별 확인, 정답 행 표시 숨김, 문항별·주제별 전환, 회차·시대·정확한 문항 번호 검색, 다시 풀기와 기록 보존을 확인했다.
- 대표 텍스트·사진·예외·조합 문항의 PC 1440px / 모바일 390px 화면과 모의고사 제출 후 노트 표시를 확인했다. 자바스크립트 오류 없음.
